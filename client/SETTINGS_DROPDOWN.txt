```jsx
const SettingsDropdownMenu = () => {
  return (
    <div className="mb-2" ref={settingsDropdownRef}>
      <button onClick={toggleSettingsDropdown}>
        <Settings size={18} />
        <span>{t('settings')}</span>
        <ChevronDown />
      </button>
      {isSettingsDropdownOpen && (
        <div className="ml-4 mt-2 space-y-1">
          <div className="px-4 py-2">
            <MobileLanguageSelector /> {/* или LanguageSelector */}
          </div>
        </div>
      )}
    </div>
  );
};
```

🧪 ПРОВЕРКА:

МОБИЛЬНАЯ ВЕРСИЯ:
1. Откройте мобильное меню (🍔)
2. Найдите пункт "⚙️ Налаштування ▼"
3. Нажмите на него - должен открыться дропдаун
4. Внутри увидите селектор языка "🇺🇦 Українська ▼"
5. Выберите другой язык - меню должно перевестись

ДЕСКТОПНАЯ ВЕРСИЯ:
1. В Navbar найдите "⚙️ Настройки ▼"
2. Нажмите на него - должен открыться дропдаун
3. Внутри увидите селектор языка
4. Выберите другой язык - интерфейс должен перевестись
