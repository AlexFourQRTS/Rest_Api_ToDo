🎯 ЗАДАЧА:
Реорганизовать API в отдельные файлы с использованием классов.
Каждый API должен быть описан с помощью классов с методами
для выполнения соответствующих операций.

═══════════════════════════════════════════════════════════════

📁 НОВАЯ СТРУКТУРА API:

src/api/
├── BaseApi.js          ← Базовый класс с общими методами
├── AuthApi.js          ← API для аутентификации
├── BlogApi.js          ← API для блога и статей
├── FileApi.js          ← API для файлов
├── UserApi.js          ← API для пользователей
├── index.js            ← Централизованный экспорт
├── authApi.js          ← DEPRECATED (старый файл)
└── blogApi.js          ← DEPRECATED (старый файл)

🏗️ АРХИТЕКТУРА:

1. BaseApi (Базовый класс):
   ✓ Общие методы для HTTP запросов
   ✓ Управление токенами
   ✓ Обработка ошибок
   ✓ Методы: get(), post(), put(), patch(), delete()

2. AuthApi (Аутентификация):
   ✓ login() - Вход в систему
   ✓ register() - Регистрация
   ✓ getProfile() - Получение профиля
   ✓ logout() - Выход
   ✓ refresh() - Обновление токена
   ✓ changePassword() - Смена пароля
   ✓ getAdminUsers() - Список пользователей (админ)
   ✓ isAdmin() - Проверка прав админа

3. BlogApi (Блог):
   ✓ getArticles() - Получение статей с пагинацией
   ✓ getArticleById() - Статья по ID
   ✓ createArticle() - Создание статьи
   ✓ updateArticle() - Обновление статьи
   ✓ deleteArticle() - Удаление статьи
   ✓ getCategories() - Список категорий
   ✓ searchArticles() - Поиск статей
   ✓ getBlogStats() - Статистика блога

4. FileApi (Файлы):
   ✓ getFiles() - Список файлов
   ✓ uploadFile() - Загрузка файла
   ✓ uploadMultipleFiles() - Загрузка нескольких файлов
   ✓ downloadFile() - Скачивание файла
   ✓ getFileInfo() - Информация о файле
   ✓ updateFileMetadata() - Обновление метаданных
   ✓ deleteFile() - Удаление файла
   ✓ getFilePreview() - Превью файла
   ✓ searchFiles() - Поиск файлов

5. UserApi (Пользователи):
   ✓ getCurrentUser() - Текущий пользователь
   ✓ updateProfile() - Обновление профиля
   ✓ uploadAvatar() - Загрузка аватара
   ✓ getUserSettings() - Настройки пользователя
   ✓ getUserActivity() - Активность пользователя
   ✓ getUserStats() - Статистика пользователя
   ✓ addFriend() - Добавить в друзья
   ✓ searchUsers() - Поиск пользователей
   ✓ getNotifications() - Уведомления

💻 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ:

// Импорт API
import { authApi, blogApi, fileApi, userApi } from './api';

// Или импорт по умолчанию
import api from './api';
const { auth, blog, file, user } = api;

// Аутентификация
const user = await authApi.login({ email, password });
const profile = await authApi.getProfile();

// Блог
const articles = await blogApi.getArticles({ limit: 10, category: 'tech' });
const article = await blogApi.createArticle({ title, content, category });

// Файлы
const files = await fileApi.getFiles({ limit: 20, type: 'image' });
const uploadedFile = await fileApi.uploadFile(file, { description: 'My file' });

// Пользователи
const currentUser = await userApi.getCurrentUser();
const settings = await userApi.getUserSettings();
